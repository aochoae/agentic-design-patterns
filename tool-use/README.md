# Tool Use Pattern (or function calling)

Enables an agent to interact with external systems through specialized tools, allowing it to retrieve information,
execute actions, and integrate with third-party services beyond text generation.

Allow an LLM to interact with external systems by invoking specialized tools when its internal knowledge is insufficient
or when an action must be performed.

When to use:

* Access real-time information.
* Query enterprise databases.
* Execute business operations.
* Integrate with external APIs.
* Perform deterministic computations.
* Access private or user-specific data.

## Running the scripts

To run the **Google ADK** script, execute the following command:

```shell
python tool_adk.py
```
